# 浮岛花园：四季三消

一个 Phaser + TypeScript 的三消小游戏基础工程。当前版本回到传统三消体验：6x6 大触控棋盘、相邻交换、三消收集目标、步数限制、清晰的成功/失败反馈。

## 架构说明

```text
src/
  core/          轻量事件总线
  data/          关卡配置
  match3/        三消核心逻辑，与 Phaser 表现层解耦
  scenes/        Phaser 场景：启动、主页、关卡
  main.ts        游戏入口
  style.css      页面容器样式
```

核心循环在 `BoardResolver` 中：

1. 交换棋子
2. 查找匹配
3. 计算特殊棋子与连锁
4. 消除并统计目标
5. 统计奖励反馈
6. 棋子下落与补充
7. 重复检测连锁

## 本地运行

## GitHub Pages 托管

项目已经内置 GitHub Actions 发布流程。把源码推送到 GitHub 仓库的 `main` 分支后，仓库会自动构建 `dist/` 并发布到 `gh-pages` 分支。

适配规则：

- 普通项目仓库会自动使用 `/<repo-name>/` 作为资源路径。
- `username.github.io` 这类用户站点仓库会自动使用根路径 `/`。

发布前需要在 GitHub 仓库中启用 Pages：

1. 打开仓库的 `Settings`。
2. 进入 `Pages`。
3. 在 `Build and deployment` 中把 `Source` 选为 `Deploy from a branch`。
4. 分支选择 `gh-pages`，目录选择 `/ (root)`。
5. 推送 `main` 分支后等待 Actions 完成。
